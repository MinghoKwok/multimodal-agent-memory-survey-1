# Audio and Speech Benchmarks

[Survey README](../../README.md) · [Audio and Speech Architecture Papers](../../architectures/audio_speech/README.md#architecture-papers) · [Scope & Terminology](../../README.md#scope--terminology)

**10 benchmark/evaluation resources**, grouped by the repository’s primary modality labels. These include dedicated memory tests, broader evaluations, and scoped comparisons. See the [scope review](../../data/benchmark_scope_review.md) for qualifications and the [Table 2 manifest](../../data/table2_benchmarks.json) for manuscript panel groupings.

Paper lists are alphabetical by system or benchmark name. `arXiv` links point to the paper’s arXiv page; `Paper` links point to the official publication or submission when an arXiv version could not be verified. The reviewed versions and evidence pointers remain in the individual records.

## Benchmark Papers

- **Agentic ASR benchmark** — Towards Human-Like Interactive Speech Recognition With Agentic Correction and Semantic Evaluation. [arXiv](https://arxiv.org/abs/2605.29430)
- **AudioMarathon** — AudioMarathon: A Comprehensive Benchmark for Long-Context Audio Understanding and Efficiency in Audio LLMs. [arXiv](https://arxiv.org/abs/2510.07293)
- **CarMem** — CarMem: Enhancing Long-Term Memory in LLM Voice Assistants through Category-Bounding. [arXiv](https://arxiv.org/abs/2501.09645)
- **ChatMem-Bench** — VoiceMem: Streaming Dual-Brain Memory for Real-Time Interaction. [arXiv](https://arxiv.org/abs/2608.26005)
- **ChronosAudio** — ChronosAudio: A Comprehensive Long-Audio Benchmark for Evaluating Audio-Large Language Models. [arXiv](https://arxiv.org/abs/2601.04876)
- **EgoMem evaluation** — EgoMem: Lifelong Memory Agent for Full-duplex Omnimodal Models. [arXiv](https://arxiv.org/abs/2509.11914)
- **H2HMem** — H2HMem: A Multimodal Memory Benchmark for Agents in Human-Human Interactions. [arXiv](https://arxiv.org/abs/2606.09461)
- **LongAudioQA** — Don't Just Listen, Try Planning: Graph-based Retrieval-Generation Agent for Long-form Audio Meeting Understanding. [arXiv](https://arxiv.org/abs/2608.24048)
- **PlanRAG-Audio evaluation** — PlanRAG-Audio: Planning and Retrieval Augmented Generation for Long-form Audio Understanding. [arXiv](https://arxiv.org/abs/2605.20414)
- **Stateful streaming ASR** — Beyond Fresh Starts: Stateful Inference for Streaming ASR in Conversational Voice Agents. [arXiv](https://arxiv.org/abs/2608.22101)
